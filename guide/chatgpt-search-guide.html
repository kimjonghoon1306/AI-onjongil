ChatGPT Search
작동 원리
완전 해설

ChatGPT Search가 어떻게 실시간 웹 검색을 수행하고 출처를 인용하는지, OAI-SearchBot의 역할을 OpenAI 공식 문서를 기반으로 설명합니다.

온종일AI 편집팀· 2026년 6월 9일· 약 5분 소요

ChatGPT Search는 ChatGPT가 실시간으로 웹을 검색하고 그 결과를 바탕으로 답변을 생성하는 기능입니다. 2024년 10월 OpenAI가 공식 출시한 이 기능은 기존 ChatGPT의 학습 데이터 한계를 보완하고, 최신 정보를 답변에 반영할 수 있게 합니다.

ChatGPT Search란?

ChatGPT Search는 ChatGPT 인터페이스 내에서 실시간 웹 검색을 수행하는 기능입니다. 사용자가 질문을 입력하면 ChatGPT는 관련 웹페이지를 검색하고, 검색 결과를 분석해 출처 링크와 함께 답변을 생성합니다.

"ChatGPT can now search the web in real time to find relevant information and provide up-to-date answers with cited sources."

— OpenAI 공식 발표 (2024년 10월)
🌐

실시간 검색

ChatGPT Search는 답변 생성 시점에 실시간으로 웹을 검색합니다. 학습 데이터 기준일과 무관하게 최신 정보를 반영할 수 있습니다.

🔗

출처 인용

답변에 사용된 웹페이지가 링크 형태로 표시됩니다. 사용자가 출처를 직접 확인할 수 있어 신뢰성이 높아집니다.

🤖

OAI-SearchBot

ChatGPT Search가 실시간으로 웹페이지에 접근할 때 사용하는 크롤러입니다. GPTBot과는 별개로 운영됩니다.

🔎

Bing 연동

ChatGPT Search는 Microsoft Bing의 검색 인덱스를 활용합니다. Bing에 인덱싱된 사이트가 ChatGPT Search에 노출될 수 있습니다.

OAI-SearchBot이란?

OAI-SearchBot은 ChatGPT Search가 실시간 답변 생성 중에 웹페이지에 접근할 때 사용하는 OpenAI의 공식 크롤러입니다. GPTBot이 모델 학습용 크롤링에 사용되는 것과 달리, OAI-SearchBot은 실시간 검색 응답 생성에 특화되어 있습니다.

📋 OpenAI 봇 종류 비교 (출처: OpenAI 공식 문서)

GPTBot: AI 모델 학습 데이터 수집용 크롤러. 크롤링된 데이터는 향후 모델 학습에 활용됩니다.

ChatGPT-User: ChatGPT가 사용자 대화 중 특정 URL을 직접 방문할 때 사용하는 에이전트.

OAI-SearchBot: ChatGPT Search 기능에서 실시간 검색 결과를 가져올 때 사용하는 크롤러.

✅ robots.txt — OAI-SearchBot 허용 방법

User-agent: OAI-SearchBot
Allow: /

ChatGPT Search 노출을 원한다면 robots.txt에서 OAI-SearchBot을 허용해야 합니다. 또한 Bingbot도 허용해야 ChatGPT Search의 Bing 인덱스 활용이 가능합니다.

ChatGPT Search에서 인용되는 방식

ChatGPT Search는 Bing 검색 결과를 기반으로 관련 페이지를 수집하고, 해당 페이지의 내용을 AI가 요약하여 답변을 생성합니다. 출처 선택에 영향을 주는 주요 요소는 다음과 같습니다.

노출이 어려운 경우
Bing에 인덱싱되지 않은 사이트
Bingbot/OAI-SearchBot 차단
관련 없는 내용 위주 페이지
매우 느린 페이지 응답 속도
노출에 유리한 경우
→ Bing 검색 결과 상위 노출 페이지
→ 질문에 직접 답하는 명확한 콘텐츠
→ LocalBusiness, FAQPage Schema 적용
→ HTTPS 적용, 빠른 응답 속도

ChatGPT Search 노출을 위한 체크리스트

✅ 1. Bing Webmaster Tools 등록

ChatGPT Search는 Bing 인덱스를 활용합니다. Bing Webmaster Tools에 사이트를 등록하고 sitemap.xml을 제출합니다. Google Search Console과 연동하면 Bing 자동 등록도 가능합니다. (Bing Webmaster Tools →)

✅ 2. Bingbot 및 OAI-SearchBot 허용

robots.txt에서 두 봇이 모두 허용되어 있는지 확인합니다.

User-agent: Bingbot
Allow: /

User-agent: OAI-SearchBot
Allow: /

✅ 3. 질문 기반 콘텐츠 작성

ChatGPT 사용자가 실제로 입력하는 질문 형태의 콘텐츠를 작성합니다. "서울 노원구 법무사 비용은 얼마인가요?", "아파트 인테리어 공사 기간은 얼마나 걸리나요?" 같은 구체적인 질문에 답하는 페이지를 구축합니다.

✅ 4. LocalBusiness Schema 적용

업체 이름, 주소, 전화번호, 영업시간 등을 LocalBusiness Schema로 마크업합니다. ChatGPT Search는 구조화 데이터를 통해 업체 정보를 더 정확하게 파악할 수 있습니다. (Schema.org LocalBusiness →)

자주 묻는 질문

Q. ChatGPT Search는 무료 사용자에게도 제공되나요?

OpenAI는 ChatGPT Search를 무료 및 유료 사용자 모두에게 제공하고 있습니다. 단, 기능의 세부 사항과 제공 범위는 OpenAI의 정책에 따라 변경될 수 있으므로 OpenAI 공식 페이지에서 최신 정보를 확인하세요. (ChatGPT Search 공식 페이지 →)

Q. GPTBot과 OAI-SearchBot을 모두 허용해야 하나요?

두 봇은 서로 다른 역할을 합니다. GPTBot은 모델 학습 데이터 수집, OAI-SearchBot은 실시간 ChatGPT Search에 사용됩니다. ChatGPT Search 노출을 위해서는 OAI-SearchBot 허용이 필수이고, 향후 모델 업데이트에 반영되길 원한다면 GPTBot도 함께 허용하는 것이 권장됩니다.

Q. ChatGPT Search와 일반 ChatGPT 응답의 차이는?

일반 ChatGPT는 모델 학습 기준일까지의 데이터만 사용합니다. ChatGPT Search는 실시간으로 웹을 검색해 최신 정보를 답변에 반영하며, 인용된 출처 링크를 함께 제공합니다. 사용자가 검색 아이콘을 활성화하거나 ChatGPT가 최신 정보가 필요하다고 판단할 때 자동으로 Search 기능이 작동합니다.
