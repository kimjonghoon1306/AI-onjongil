진단기란?

온종일AI 최적화 진단기는 웹사이트 URL을 입력하면 ChatGPT·Perplexity·Gemini·Claude 같은 AI 검색 플랫폼에서 얼마나 잘 노출될 수 있는지를 5개 영역으로 분석하는 무료 도구입니다. 메타태그, Schema 구조화 데이터, robots.txt, sitemap.xml, 콘텐츠 품질 등을 실측해 점수와 개선 항목을 즉시 알려줍니다.

사용방법 — 4단계

1

URL 입력

분석할 웹사이트 주소를 입력창에 붙여넣습니다. https:// 없이 도메인만 입력해도 자동으로 처리됩니다. 자신의 사이트뿐 아니라 경쟁 업체 사이트도 분석할 수 있습니다.

2

분석 실행

'분석하기' 버튼을 클릭하거나 Enter 키를 누릅니다. URL 확인 → 기술 분석 → 콘텐츠 검사 → AI 최적화 → 완료의 5단계로 진행됩니다. 보통 5~15초 내에 완료됩니다.

3

결과 확인

종합 점수(0~100점)와 5개 영역별 점수, 항목별 PASS/FAIL 목록이 나타납니다. 빨간 FAIL 항목은 즉시 개선 가능한 포인트입니다.

4

저장 & 개선

'PDF 저장' 버튼으로 결과를 다운로드해 보관하거나 공유할 수 있습니다. 개선 후 다시 분석하면 점수 변화를 확인할 수 있습니다.

점수 기준 이해하기

진단기는 실측 데이터가 수집되면 5개 영역, 실측 불가 시 4개 영역으로 채점합니다.

영역별 주요 진단 항목

SEO 검색 엔진 최적화

  • title 태그 — 페이지 제목이 있고 60자 이내인지
  • meta description — 설명이 있고 120~160자인지
  • canonical URL — 중복 페이지 대표 URL 지정 여부
  • og:title / og:image — 소셜 공유 메타태그
  • viewport — 모바일 반응형 설정 여부

AEO AI 답변 최적화

  • FAQPage Schema — FAQ 구조화 데이터 존재 여부
  • FAQ 완성도 — 질문·답변 쌍이 3개 이상인지
  • Q&A 콘텐츠 구조 — 실제 질문 형식의 H2/H3 제목 포함 여부
  • 답변 명확성 — AI가 그대로 인용할 수 있는 단문 답변 여부

AEO는 ChatGPT·Perplexity가 질문에 답할 때 내 사이트 내용을 그대로 인용하게 만드는 구조입니다. FAQPage Schema가 없으면 점수가 크게 낮아집니다.

GEO 지역 AI 최적화

  • LocalBusiness Schema — 업체 정보 구조화 데이터
  • name / address / telephone — 7개 필수 필드 완성도
  • NAP 일관성 — 전화번호·주소·이메일이 텍스트에 노출되는지

지역 기반 업종(병원·음식점·학원 등)이라면 GEO 점수가 특히 중요합니다. "강남 치과 추천" 같은 지역 질문에서 AI가 참고하는 신호입니다.

기술 기술적 접근성

  • robots.txt — GPTBot·PerplexityBot·ClaudeBot·Googlebot·Applebot 허용 여부
  • sitemap.xml — 존재 여부와 URL 수
  • 응답 속도 — 페이지 로딩 속도
  • 색인 허용 — noindex 태그 없는지

robots.txt에서 GPTBot을 막고 있으면 ChatGPT가 사이트를 아예 크롤링하지 않습니다. 가장 먼저 확인해야 할 항목입니다.

콘텐츠 품질 실측 분석 시 제공

  • 단어 수 — 주요 페이지 콘텐츠가 충분한지
  • 이미지 alt 비율 — 이미지에 대체 텍스트가 있는지
  • 외부 링크·인용 — 신뢰할 수 있는 출처 링크 여부
  • E-E-A-T 신호 — about·contact·author·privacy 페이지 존재 여부
  • 헤딩 구조 — H1→H2→H3 올바른 계층 구조

자주 묻는 질문

진단기는 무료인가요? ▾

네, 완전 무료입니다. 횟수 제한 없이 사용할 수 있습니다.

어떤 사이트를 분석할 수 있나요? ▾

공개된 웹사이트라면 모두 분석할 수 있습니다. 자신의 사이트는 물론 경쟁 업체 사이트도 분석 가능합니다. 단, 네이버 블로그·카카오맵처럼 외부 크롤링이 차단된 플랫폼은 일부 항목(콘텐츠 품질)이 분석되지 않습니다.

점수가 낮으면 AI 검색에 안 나오는 건가요? ▾

낮은 점수 = AI에 전혀 안 나오는 건 아닙니다. 점수는 AI가 내 사이트를 인용할 가능성 지표입니다. 점수가 낮을수록 AI가 경쟁 사이트를 더 자주 인용할 가능성이 높아집니다.

어떤 항목을 먼저 개선해야 하나요? ▾

우선순위: ① robots.txt AI 봇 허용 → ② FAQPage Schema 추가 → ③ LocalBusiness Schema 완성 → ④ meta description 작성 순으로 개선하면 단기간에 점수 향상을 기대할 수 있습니다.

결과를 저장할 수 있나요? ▾

결과 화면 하단 'PDF 저장' 버튼으로 진단 결과를 PDF로 다운로드할 수 있습니다. 개선 전·후 결과를 저장해 비교해보세요.

점수를 올리고 싶은데 혼자 하기 어려워요 ▾

온종일AI 컨설팅을 통해 진단 결과를 바탕으로 Schema 추가, 콘텐츠 구조 개편, robots.txt 수정 등 전체 최적화를 대행해드립니다. tarry9653@daum.net으로 문의해주세요.

점수를 빠르게 올리는 핵심 팁

🤖

AI 봇 크롤링 허용

robots.txt에 User-agent: GPTBot 허용 설정이 없으면 ChatGPT가 사이트를 읽지 않습니다. 가장 빠른 개선 항목입니다.

❓

FAQPage Schema 추가

고객이 자주 하는 질문 3~5개를 JSON-LD로 마크업하면 AI가 답변할 때 내 사이트 내용을 그대로 인용하는 빈도가 높아집니다.

📍

LocalBusiness Schema 완성

업체명·주소·전화번호·영업시간·업종을 Schema.org 표준으로 작성하면 지역 기반 AI 검색에서 우선 노출됩니다.

📝

meta description 최적화

120~160자로 명확하게 작성된 meta description은 AI가 사이트 요약을 인용할 때 직접 활용합니다.

🗺️

sitemap.xml 등록

sitemap.xml이 없으면 AI 크롤러가 전체 페이지를 발견하지 못할 수 있습니다. 모든 중요 페이지 URL을 포함시키세요.

⭐

E-E-A-T 신호 강화

About·Contact 페이지 작성, 작성자 정보 추가, 개인정보처리방침 페이지 등이 있으면 AI가 신뢰할 수 있는 출처로 인식합니다.
